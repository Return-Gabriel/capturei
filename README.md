# Capturei

**Captura, desenho e edição de tela para Windows, sem perder qualidade.**
Gratuito · em português · funciona offline · desenvolvido por **GhostDev**

## ⬇️ Baixar

**[Baixar o Capturei para Windows](https://github.com/Return-Gabriel/capturei/releases/latest)**

Na página de download, clique em **`Capturei-Setup-x.y.z.exe`** e execute o arquivo. A instalação não pede administrador e não exige nenhum outro programa. Funciona em Windows 10 e 11 de 64 bits.

> Na primeira execução, o Windows pode mostrar o aviso **"O Windows protegeu o computador"**. Ele aparece porque o aplicativo ainda não tem assinatura digital, não porque haja algum problema. Clique em **Mais informações → Executar assim mesmo**.

Depois de instalado, o Capturei **avisa sozinho quando sai uma versão nova** e atualiza com um clique.

## O que ele faz

- **Captura do jeito que você quiser:** região, janela, **forma livre** (contorne qualquer área com o mouse), tela inteira ou só um monitor.
- **Barra de opções na seleção:** depois de escolher a área, ajuste pelas alças e escolha **Capturar · Rolagem auto · Rolar eu mesmo · Copiar · Salvar · Editar**.
- **Captura com rolagem:** selecione um bloco que rola (página, conversa, lista) e junte tudo numa imagem só. O Capturei pode rolar sozinho, ou você mesmo rola com a roda do mouse no seu ritmo.
- **Desenhar na tela:** congela a tela para você rabiscar, destacar e apontar antes de capturar.
- **Editor completo:** setas (com ponta dupla), linhas, retângulos, círculos, desenho livre, marca-texto, texto, numeração de passos, pixelar dados sensíveis e recortar.
- **Tudo continua editável:** arraste as pontas da seta para o lugar exato, redimensione formas pelas alças e troque cor e tamanho quando quiser.
- **Sem perda de qualidade:** captura na resolução real de cada monitor, e a imagem nunca é reamostrada.
- **Atalhos configuráveis:** Print Screen por padrão, e você escolhe as teclas de cada tipo de captura.

## Atalhos padrão

| Ação | Atalho |
|---|---|
| Capturar (modo escolhido) | `Print Screen` |
| Região / janela | `Ctrl + Shift + X` |
| Forma livre | `Ctrl + Print Screen` |
| Com rolagem (página/bloco inteiro) | `Ctrl + Alt + Print Screen` |
| Tela inteira | `Shift + Print Screen` |
| Desenhar na tela | `Ctrl + Shift + Print Screen` |

## Conferir o download (opcional)

Cada versão traz o arquivo `SHA256SUMS.txt`. Para conferir se o instalador não foi alterado, rode no PowerShell:

```powershell
Get-FileHash .\Capturei-Setup-1.0.1.exe -Algorithm SHA256
```

O código precisa ser igual ao que está no `SHA256SUMS.txt`.
